# Звіт

## Автоматична документація модуля `main`

### 1. Мета роботи

Створити документацію до програмного модуля кавового автомата за допомогою автоматичної системи документування.

### 2. Об'єкт документування

Документується модуль `main.py`. Основний клас модуля — `CoffeeMachine`, який відповідає за:

- рецепти напоїв;
- облік води, молока, цукру, стаканчиків і зерен;
- оплату готівкою та банківською карткою;
- розрахунок і видачу здачі;
- поповнення запасів;
- облік та інкасацію виручки.

### 3. Використаний інструмент

Для автоматичного створення документації використано стандартний інструмент Python `pydoc`. Він формує HTML-сторінку на основі структури модуля та його docstring-описів.

Команда повторної генерації:

```powershell
.\generate_docs.ps1
```

### 4. Документований API

| Елемент | Призначення |
| --- | --- |
| `CoffeeMachine.buy()` | Перевіряє запаси й оплату, готує напій та повертає здачу. |
| `CoffeeMachine.fill()` | Поповнює інгредієнти та грошові запаси з урахуванням місткості. |
| `CoffeeMachine.take()` | Забирає виручку та обнуляє лічильники доходу. |
| `CoffeeMachine.available_coins` | Повертає загальну суму доступних монет. |
| `CoffeeMachine.available_bills` | Повертає загальну суму доступних купюр. |
| `CoffeeMachine._make_change()` | Формує набір купюр і монет для видачі здачі. |

### 5. Результат

[Відкрити згенеровану HTML-документацію](docs/main.html)

У документації наведено опис модуля, класу `CoffeeMachine`, його констант, властивостей і методів.

### 6. Перевірка

Після внесення змін виконано модульні тести:

```text
Ran 5 tests in 0.001s
OK
```

### 7. Висновок

Для модуля `main.py` підготовлено автоматично структуровану HTML-документацію. Звіт містить покликання на результат генерації та команду, якою документацію можна оновити після змін у коді.
