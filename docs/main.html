Документація модуля main

PyQt5 coffee machine with stock, payment, and change management.

Клас CoffeeMachine

Зберігає рецепти кави, інгредієнти, готівку та операції купівлі.

Публічний API

ЕлементОпис
buy(...)Перевіряє запаси й оплату, готує напій та повертає статус, повідомлення і здачу.
fill(...)Поповнює інгредієнти та гроші, не перевищуючи місткість автомата.
take()Забирає виручку та обнуляє лічильники доходу.
available_coinsПовертає загальну суму доступних монет.
available_billsПовертає загальну суму доступних купюр.
_make_change(amount)Формує набір купюр і монет для заданої суми здачі.

Інші компоненти

CoffeeWindow реалізує графічне вікно PyQt5 для взаємодії з автоматом.
